Example: Ajouter un produit dans Symfony

1) Via un formulaire Web (approche standard)

- Fichier: src/Form/ProduitsType.php
<?php

namespace App\Form;

use App\Entity\Produits;
use Symfony\Component\Form\AbstractType;
use Symfony\Component\Form\Extension\Core\Type\TextType;
use Symfony\Component\Form\Extension\Core\Type\TextareaType;
use Symfony\Component\Form\Extension\Core\Type\MoneyType;
use Symfony\Component\Form\FormBuilderInterface;
use Symfony\Component\OptionsResolver\OptionsResolver;

// Ce type de formulaire définit les champs qui seront affichés et mappés
// vers l'entité Produits.
class ProduitsType extends AbstractType
{
    // buildForm() construit la structure du formulaire.
    public function buildForm(FormBuilderInterface $builder, array $options): void
    {
        $builder
            // Champ texte pour le nom du produit
            ->add('nom', TextType::class)
            // Zone de texte pour la description
            ->add('description', TextareaType::class)
            // Champ prix formaté en euros
            ->add('prix', MoneyType::class, ['currency' => 'EUR'])
            // Champs optionnels pour image, couleur, matière et forme
            ->add('image', TextType::class, ['required' => false])
            ->add('couleur', TextType::class, ['required' => false])
            ->add('matiere', TextType::class, ['required' => false])
            ->add('forme', TextType::class, ['required' => false])
        ;
    }

    // configureOptions() indique que ce formulaire mappe l'entité Produits.
    public function configureOptions(OptionsResolver $resolver): void
    {
        $resolver->setDefaults([
            'data_class' => Produits::class,
        ]);
    }
}

- Controller action (src/Controller/ServiceController.php)
public function addProduit(Request $request, EntityManagerInterface $em): Response
{
    // On crée une nouvelle entité Produits qui va recevoir les valeurs du formulaire.
    $produit = new \App\Entity\Produits();

    // On construit le formulaire à partir du type ProduitsType et de l'objet Produits.
    $form = $this->createForm(\App\Form\ProduitsType::class, $produit);

    // Récupère les données de la requête HTTP et les applique au formulaire.
    $form->handleRequest($request);

    // Si le formulaire a été envoyé et que les valeurs sont valides,
    // on enregistre l'entité en base de données.
    if ($form->isSubmitted() && $form->isValid()) {
        $em->persist($produit);
        $em->flush();

        // Redirige vers la page des services après l'ajout.
        return $this->redirectToRoute('app_service');
    }

    // Affiche le formulaire si rien n'a été envoyé ou si les données sont invalides.
    return $this->render('service/add.html.twig', [
        'form' => $form->createView(),
    ]);
}

- Template: templates/service/add.html.twig (very simple)
{% raw %}
{# form_start ouvre la balise <form> et ajoute le token CSRF #}
{{ form_start(form) }}

{# form_row affiche le label + le champ pour chaque propriété #}
{{ form_row(form.nom) }}
{{ form_row(form.description) }}
{{ form_row(form.prix) }}

<button type="submit">Ajouter</button>

{# form_end ferme la balise <form> et ajoute les éléments cachés nécessaires #}

{% endraw %}

Notes:
- Ajoutez des contraintes de validation dans l'entité (use Symfony\Component\Validator\Constraints as Assert).
- Protégez la route si nécessaire (security/firewall).

2) Via une API JSON (POST /api/produits)

- Controller minimal (src/Controller/Api/ProduitsApiController.php)
<?php

namespace App\Controller\Api;

use App\Entity\Produits;
use Doctrine\ORM\EntityManagerInterface;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\Routing\Annotation\Route;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\Serializer\SerializerInterface;
use Symfony\Component\Validator\Validator\ValidatorInterface;

class ProduitsApiController extends AbstractController
{
    // Cette route reçoit les requêtes POST sur /api/produits.
    #[Route('/api/produits', name: 'api_produits_create', methods: ['POST'])]
    public function create(Request $request, SerializerInterface $serializer, EntityManagerInterface $em, ValidatorInterface $validator): JsonResponse
    {
        // On récupère le corps brut de la requête JSON.
        $data = $request->getContent();

        try {
            // On transforme le JSON en objet Produit.
            $produit = $serializer->deserialize($data, Produits::class, 'json');
        } catch (\Exception $e) {
            // Si le JSON est invalide, on renvoie une erreur 400.
            return new JsonResponse(['error' => 'Invalid JSON'], 400);
        }

        // On valide l'objet produit avec les contraintes déclarées dans l'entité.
        $errors = $validator->validate($produit);
        if (count($errors) > 0) {
            $errorsString = (string) $errors;
            return new JsonResponse(['error' => $errorsString], 400);
        }

        // Si tout est OK, on enregistre le produit en base.
        $em->persist($produit);
        $em->flush();

        // On renvoie l'identifiant du nouveau produit en JSON.
        return new JsonResponse(['id' => $produit->getId()], 201);
    }
}

- Example curl
curl -X POST http://localhost:8000/api/produits \
  -H "Content-Type: application/json" \
  -d '{"nom":"Mon produit","description":"Une description","prix":19.99,"image":"/img.jpg","couleur":"rouge","matiere":"bois","forme":"ronde"}'

Notes & recommandations:
- Activez et configurez le component Serializer (composer require symfony/serializer) et les groupes si nécessaire.
- Ajoutez des règles de validation dans l'entité `Produits` (annotations ou attributs `Assert`).
- Protégez l'API (JWT, OAuth2, ou session) selon l'utilisation.
- Gérez les erreurs et renvoyez des codes HTTP appropriés (400 pour payload invalide, 401/403 pour auth).

Migrations DB:
Après modification d'entité, créer puis exécuter la migration:

php bin/console make:migration
php bin/console doctrine:migrations:migrate
